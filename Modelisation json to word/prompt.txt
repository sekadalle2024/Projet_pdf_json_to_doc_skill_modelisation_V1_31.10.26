# [CONTEXTE]
- Dossier de travail : **`Modelisation claude opus`**. Il contient :
  1. le script **`json_to_word.py`** ;
  2. un ou plusieurs fichiers JSON à convertir (extension `.json`).
- Le script transforme des données JSON en documents Word (.docx), avec la charte graphique du modèle « Matrice de surveillance permanente » :
  - A4 paysage, police Calibri ;
  - en-têtes de tableau bordeaux `7B1E3A` avec texte blanc en gras ;
  - première colonne rose pâle `F2E6EA` ;
  - bordures grises `999999` ;
  - ligne d'en-tête répétée sur chaque page ;
  - lignes qui ne se coupent pas entre deux pages ;
  - en-tête et pied de page avec pagination « Page X / Y ».
- **Structure JSON attendue** (feuille de couverture d'audit) :
  - La racine est un objet dont chaque clé est un nom de feuille. Exemple : `"Etape mission - Feuille couverture"`.
  - La valeur de la feuille est une liste de tableaux. Chaque tableau est un objet à une clé, dont la valeur est une liste d'enregistrements. Exemple : `{"table 3": [ {"no": "1", "travaux a effectuer": "..."}, ... ]}`.
  - Les tableaux de ce type sont : `table 0 - Signature worksheet`, `table 1`, `table 2` (OBJECTIFS), `table 3` (travaux à effectuer), `table 4` (résultats des tests), `table 5` (tableau de test détaillé, environ 18 colonnes), `table 6 - Cross references documentaire`, `table 7 - Legendes`, `table 8 - Revue manager`.
  - Un même fichier peut contenir **plusieurs objets JSON racine à la suite** (exemple : deux feuilles de couverture). Chaque objet racine produit un document Word distinct.
  - Le script tolère aussi : `{"feuille": {"tableau": [...]}}`, `{"feuille": [ {...}, {...} ]}`, une liste d'enregistrements seule, et des valeurs imbriquées (listes ou sous-objets, aplaties en texte).
- **Mise en forme automatique selon la forme du tableau** :
  - 1 enregistrement avec 1 seul champ : bloc de texte avec en-tête bordeaux (exemple : OBJECTIFS).
  - 1 enregistrement avec 6 champs courts au plus : tableau compact horizontal (exemple : signatures).
  - 1 enregistrement avec des champs longs : fiche « Rubrique / Description ».
  - Plusieurs enregistrements : tableau à colonnes. Les largeurs s'adaptent au contenu, la police diminue quand le nombre de colonnes augmente, les marges se réduisent au-delà de 12 colonnes, et les nombres comme « 34 000 000 » ne se coupent pas.
  - Coloration automatique : « Non-satisfaisant » et « - » en rouge pâle, « Satisfaisant » et « + » en vert pâle.
  - Le préfixe « table N - » est retiré des titres. Les tableaux sans nom n'ont pas de titre.
  - Le nom du fichier de sortie vient de la colonne `Reference` quand elle existe (partie avant « - », exemple `FC-BK-A10.docx`). Sinon : `<nom_du_json>_<numéro>.docx`.
- Syntaxe : `python json_to_word.py <entree.json | dossier> [sortie] [--fusion] [--titre "..."] [--pied "..."] [--sans-couleurs] [--ecraser]`
  - `sortie` : dossier de sortie (par défaut `./sorties_word`), ou fichier `.docx` quand `--fusion` est utilisé.
  - `--fusion` : un seul .docx pour tous les objets JSON. Chaque objet commence sur une nouvelle page.
  - `--ecraser` : sans cette option, un fichier existant n'est jamais écrasé et un suffixe date/heure est ajouté.
  - Dépendance : `python-docx`.

# [LIMITES CONNUES DU SCRIPT : À SIGNALER, PAS À CONTOURNER EN SILENCE]
- **Ordre des colonnes** : les colonnes d'un tableau suivent l'ordre d'apparition des clés dans le JSON. Si les enregistrements n'ont pas tous les mêmes clés, les colonnes manquantes sont laissées vides. Signale-le-moi.
- **Tableau de plus de 14 colonnes** : le script réduit la police (7 pt) et les marges. Signale-moi tout tableau de plus de 20 colonnes, car la lisibilité peut se dégrader. Propose alors de scinder le tableau dans le JSON ou d'utiliser un format de page plus grand, sans le faire toi-même.
- **Valeurs imbriquées** : les listes sont aplaties en texte (un élément par ligne), les sous-objets en lignes « clé : valeur ». La structure d'origine n'est plus visible dans le Word.
- **Coloration** : elle s'applique à toute cellule (hors première colonne) dont le texte est exactement « Non-satisfaisant », « Satisfaisant », « + » ou « - ». Si un « - » sert de simple placeholder dans une autre colonne, signale-le-moi et propose `--sans-couleurs`.
- **Titres des tableaux** : un tableau sans nom (`table 3`, `table 4`, etc.) n'a pas de titre dans le Word. C'est voulu.
- **Noms de fichiers** : si deux objets ont la même référence, le second reçoit un suffixe date/heure. Signale-le-moi.
- **Mise en page** : le script ne gère ni images, ni formules, ni mise en forme conditionnelle autre que la coloration décrite ci-dessus.
