## 🔍 Ce que le Skill Fait

### 1️⃣ Recherche Multi-Sources
- Sites d'emploi africains (emploi.ci, opportunitesausenegal.sn)
- Sites internationaux filtrés Afrique (Indeed, LinkedIn)
- Sites d'entreprises (Ecobank, BAD, UBA)
- Organisations internationales (UNDP, UNICEF, BAD)

### 2️⃣ Recherche Intelligente
- ✅ Bilingue (Français + Anglais)
- ✅ Variantes de postes ("Directeur Audit" = "Head of Internal Audit")
- ✅ Par pays et par ville
- ✅ Par secteur et par entreprise
- ✅ Par année (2020-2026)

### 3️⃣ Extraction Structurée
Pour chaque offre:
- ✅ Titre du poste
- ✅ Entreprise
- ✅ Localisation
- ✅ Date de publication
- ✅ Description
- ✅ Compétences requises
- ✅ Expérience demandée
- ✅ Source/URL

### 4️⃣ Analyse Approfondie
- 📊 Tendances du marché
- 💼 Compétences les plus demandées
- 🏢 Secteurs les plus actifs
- 📈 Évolution temporelle
- 👤 Profil type

## ⚙️ Comment l'Utiliser

### Étape 1: Formuler la Requête
```
Trouve [NOMBRE] offres pour [FONCTION] en [ZONE GÉOGRAPHIQUE]
```

### Étape 2: Le Skill Lance Automatiquement
- 10-15 recherches web ciblées
- Extraction des informations
- Déduplication
- Structuration

### Étape 3: Recevoir le Rapport
- Fichier markdown complet
- Offres détaillées par pays
- Analyse des tendances
- Statistiques et insights

### Durée Moyenne
- 2-3 heures pour 30-50 offres
- Dépend de la spécificité du poste
- Dépend de la zone géographique

---

## 🔧 Optimisations Possibles

### Pour Plus d'Offres
1. Élargir la période (ex: 7 ans au lieu de 5)
2. Inclure postes connexes (ex: "Contrôle Interne" avec "Audit")
3. Étendre la zone géographique
4. Accepter niveaux variés (junior à senior)

### Pour Plus de Détails
1. Consulter sites carrières entreprises directement
2. Utiliser LinkedIn Sales Navigator
3. Contacter DRH pour infos non publiques
4. Croiser avec annuaires professionnels

### Pour Automatiser
1. Script Python avec scraping
2. Intégration API LinkedIn/Indeed
3. Monitoring continu
4. Alertes automatiques
