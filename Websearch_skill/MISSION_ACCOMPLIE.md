## 🚀 UTILISATION IMMÉDIATE

### Pour Chercher un Emploi
```
1. Ouvrir: resultats_pdf/Directeur_Audit_Interne/
2. Lire: README.md (5 min)
3. Choisir PDF selon besoin:
   - Vue complète → PDF 01
   - Top offres → PDF 02
   - Synthèse → PDF 03
4. Postuler aux offres sélectionnées
```

### Pour Ajouter une Fonction
```
1. Lancer: Trouve [X] offres pour [FONCTION] en [ZONE]
2. Exécuter: python convert_to_pdf.py
3. Créer: nouveau dossier dans resultats_pdf/
4. Ajouter: README.md de la fonction
5. MAJ: INDEX.md et VUE_ENSEMBLE.md
```
