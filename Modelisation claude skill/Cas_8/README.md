# Cas 8 - Modèles Standards Multi-Usage (API N8N)

## Description
Génération de divers documents standardisés d'audit (cartographies, matrices, plans).

## Skill à Développer
- **Skill Natif** : À générer depuis Claude Opus
- **Skill Standard** : `audit-etap_mission_feuille_modele_standard.skill`

## Étapes de Mission
- **Programme de travail** : Planning détaillé des missions
- **Cartographie des risques** : Heat maps et matrices risques
- **Modélisation** : Modèles de processus et flux
- **Plan de recommandation de surveillance permanente** : Plans de contrôle permanent
- **Matrice de surveillance permanente** : Tableaux de bord surveillance

## Workflow N8N
- **Webhook URL** : À définir
- **Méthode** : POST/GET
- **Champ de sortie** : `Data_integrale`

## Caractéristiques
- ⏳ **Mode** : API N8N (à configurer)
- ⏳ **Multi-formats** : Support de multiples types de documents
- ⏳ **Tableaux complexes** : Matrices, heat maps, cartographies
- ⏳ **Graphiques** : Visualisations de risques
- ⏳ **Horodatage** : Format standard V1

## Types de Documents
1. **Programme de travail** : Planning missions avec jalons
2. **Cartographie risques** : Matrices Impact/Probabilité
3. **Modélisation** : Flowcharts et diagrammes processus
4. **Plans surveillance** : Tableaux de bord contrôle permanent
5. **Matrices surveillance** : Grilles de suivi opérationnel
